# Bookshelf interaction experiment

Question: can project links feel like physical books pulled out of a shelf, while preserving the existing list, filtering and navigation?

Run `pnpm dev --background` and visit `/luis-amrein-portfolio/work/#case-studies`.

The default is stacked volumes. The development-only bottom switcher and left/right arrow keys compare `?variant=stacked`, `?variant=upright`, and `?variant=covers`. The same collection is on the homepage. Each book has a stable hit area, a spring-driven pull, cloth grain, raised spine edges, foil lettering, page blocks and a changing cast shadow. Keyboard focus also pulls the book forward. Reduced motion disables displacement; touch follows links directly.

Evaluation: pending user review. Keep this experiment on `experiment/bookshelf-interaction`; no design has been selected for publication.
